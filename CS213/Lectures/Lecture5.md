We have std::list in c++ which has the same implementation as we for the doubly linked list with a 
sentinel node .

We use an iterator instead of a pointer to traverse the list,

for p->next we use it++ and for p->prev we use it-- 

the iterator (it) supports the following operations:

1)*
2)->
3)++
4)--
5)==
6)!=
